# Noteline Homebrew tap

Markdown notes in local `.md` files, with offline Word (`.docx`) and PDF export.

```sh
brew install --cask flowlab-works/tap/noteline
```

Apple Silicon requires macOS Sonoma 14 or later; Intel requires macOS Monterey 12 or later.
The desktop app has a 14-day trial for new installations, followed by a one-time paid license. Existing trials keep their original duration.

[Download and product details](https://noteline.io/download) · [Pricing](https://noteline.io/pricing) · [Support](https://noteline.io/support)

Published by The Noteline Team. This tap uses the official signed and notarized release installers. The application also supports its own updater.
